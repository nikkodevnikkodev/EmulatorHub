\# ⚡ Emulator \& Game Hub



A modern, fast, and customizable Windows launcher for all your emulators and games, built with Python and Tkinter.



!\[UI Preview](https://via.placeholder.com/800x450.png?text=Emulator+%26+Game+Hub+UI)



\## 🌟 Features

\- 🎯 \*\*Direct Game Launching\*\*: Launch your favorite games with custom paths and direct execution flags.

\- 🖼️ \*\*Cover Art System\*\*: Automatically fetches or lets you manually pick custom game cover art (JPG, PNG, WebP).

\- 🎨 \*\*Modern Dark UI\*\*: Clean interface with high-contrast purple/blue gaming accents.

\- 📂 \*\*Isolated Data Storage\*\*: Configurations and covers are stored safely in `%appdata%\\\\\\\\EmulatorLauncher\\\\\\\\`.



\---



\## 🚀 Installation \& Usage



1\. Go to the \*\*\[Releases](../../releases)\*\* page.

2\. Download the latest `EmulatorHub.exe`.

3\. Run the `.exe` file directly — no installation required!
